## 🎙️ Voice Source & Recording Logic

### মূল Voice Source

**Microphone-এর voice-ই হবে Final Recording-এর মূল voice।**

অর্থাৎ:

- 🎥 **Main Video**
  - অন্য ব্যক্তির video/visual reference থাকবে।
  - Main Video-তে voice থাকলেও সেটি Teleprompter-এর source হবে না।
  - Main Video-এর audio Final Recording-এর voice হিসেবে ব্যবহার করা হবে না।

- 🎙️ **Microphone**
  - Mentor / **Shah Neil Khan** যা বলবেন, সেটাই Final Recording-এর মূল voice হবে।
  - Microphone থেকে সরাসরি voice capture হবে।

- 📝 **Voice-to-Text / Teleprompter**
  - Shah Neil Khan-এর Microphone voice → Voice-to-Text
  - Voice-to-Text → Teleprompter
  - Teleprompter text → Auto Type
  - Text প্রয়োজন অনুযায়ী → Auto Scroll
  - Teleprompter শুধু Mentor-এর screen-এ দেখা যাবে।

- 🎬 **Final Recording**
  - Main Video-এর visual/reference থাকবে।
  - Shah Neil Khan-এর Microphone voice থাকবে।
  - Shah Neil Khan-এর camera থাকবে।
  - **UshaLiveAI** Brand Label থাকবে।
  - Teleprompter final video-তে থাকবে না।

- ❌ **Teleprompter**
  - Final recording-এর অংশ হবে না।
  - Recorded video-তে কোনো Teleprompter text দেখা যাবে না।
  - এটি শুধুমাত্র Mentor-এর live reading/reference layer হিসেবে কাজ করবে।

## 🔄 Complete Flow

**Main Video**
→ অন্য ব্যক্তির Visual / Reference

**Microphone**
→ Shah Neil Khan-এর Voice

**Shah Neil Khan-এর Microphone Voice**
→ Voice-to-Text
→ Teleprompter
→ Auto Type
→ Auto Scroll

**Final Recording**
→ Main Video Visual
+ Shah Neil Khan-এর Microphone Voice
+ Shah Neil Khan Camera
+ UshaLiveAI Brand

❌ Teleprompter বাদ থাকবে

**Final Recording = আপনার Voice + Main Video + Shah Neil Khan Camera + Brand**
