# 🎥 Zoom-Style Video Recording & Teleprompter — Feature Requirements

## 1. Main Video Stage

- Main Video পুরো stage fill করবে।
- `object-fit: cover` ব্যবহার করতে হবে, যাতে ভিডিও বড় ও immersive দেখায়।
- Main stage-এর UI Zoom-এর মতো clean, professional এবং easy-to-use হবে।

## 2. Mentor Camera — Draggable

- Mentor-এর camera box draggable হবে।
- Mouse দিয়ে drag করা যাবে।
- Touch device-এ touch/drag support থাকবে।
- Camera box যেকোনো suitable position-এ নেওয়া যাবে।
- Camera box-এর position recording-এর সময়ও পরিবর্তন করা যাবে।

## 3. Mentor Name / Camera Label

- Mentor camera label-এ নাম থাকবে:
  **Shah Neil Khan**
- Camera box এবং তার label একই draggable component হিসেবে কাজ করবে।
- Label-এর design clean ও professional হবে।

## 4. Main Stage Brand Label

- Main video stage-এ Brand Name label থাকবে।
- Brand Name label-ও draggable হবে।
- User প্রয়োজন অনুযায়ী label-এর position পরিবর্তন করতে পারবে।

## 5. Voice Text / Teleprompter

- একটি আলাদা **Voice Text / Teleprompter panel** থাকবে।
- Mentor যে text দেখে দেখে কথা বলবেন, সেটি এই panel-এ দেখা যাবে।
- Teleprompter-এর text **Main Video-এর ভিতরে দেখা যাবে না**।
- এটি শুধু Mentor-এর reading/reference interface হিসেবে কাজ করবে।

## 6. Main Video থেকে Voice Text তৈরি

- Main video-এর speech/voice থেকে Voice Text তৈরি করার ব্যবস্থা থাকবে।
- Speech-to-Text / transcription ব্যবহার করে spoken voice → text করা হবে।
- তৈরি হওয়া text Teleprompter / Voice Text panel-এ দেখাবে।
- Recording চলাকালীন Mentor নিজের screen-এ এই text দেখতে পারবেন।

## 7. Final Recorded Video-তে Teleprompter থাকবে না

- Recording চলার সময় Voice Text / Teleprompter screen-এ visible থাকবে।
- কিন্তু final recorded video export করার সময় Teleprompter একদম capture হবে না।
- Final video-তে শুধু Main Video, Mentor Camera এবং প্রয়োজনীয় stage elements থাকবে।
- Teleprompter panel final recording-এর অংশ হবে না।
- UI overlay আলাদা layer হিসেবে রাখতে হবে যাতে recording canvas-এর বাইরে থাকে।

## 8. Mentor Camera Background

Mentor camera-এর পিছনের background পরিবর্তন করার option থাকবে।

সম্ভাব্য options:

- Custom image background
- Uploaded image
- Default background
- Blur background
- Strong blur / soft blur
- Background off / transparent-style effect (যদি প্রযুক্তিগতভাবে সম্ভব হয়)

User নিজের পছন্দের ছবি camera background হিসেবে ব্যবহার করতে পারবে।

## 9. Blur Screen / Background Effect

- Mentor camera background blur করা যাবে।
- Blur intensity adjustable হলে ভালো।
- Main video blur নয়; প্রয়োজন অনুযায়ী Mentor camera-এর background blur হবে।
- UI থেকে background mode পরিবর্তন করা যাবে।

## 10. Zoom-Style Interface

Interface দেখতে Zoom-এর মতো professional video meeting / recording application-এর feel থাকবে।

মূল characteristics:

- Large central video stage
- Floating Mentor camera
- Bottom control bar
- Optional side panel
- Clear recording controls
- Minimal but professional layout
- Dark video-focused workspace
- Smooth interaction

## 11. Preferred Color

Primary preferred color:

**Green**

Green accent ব্যবহার করা হবে:

- Record button/status
- Active controls
- Selected states
- Buttons
- Focus indicators
- Important UI highlights

Color palette modern ও professional রাখতে হবে।

## 12. Glassmorphism UI

UI style হবে:

**Glassmorphism**

Design characteristics:

- Semi-transparent glass panels
- Backdrop blur
- Soft border
- Subtle shadow
- Rounded corners
- Modern dark background
- Green accent
- Premium but clean appearance

Glass effect অতিরিক্ত heavy না করে readable ও usable রাখতে হবে।

## 13. Student Panel — Optional / Small

ডান পাশে Student view থাকা জরুরি নয়।

যদি Student panel রাখা হয়:

- Small/scaled view হতে পারে।
- Sidebar বা mini thumbnail হিসেবে রাখা যেতে পারে।
- Main video stage-এর জায়গা নষ্ট করা যাবে না।
- User চাইলে panel hide/collapse করতে পারবে।

Priority:

**Main Video + Mentor Camera + Teleprompter > Student Panel**

## 14. Suggested Screen Layout

### Main Area

- Full-size Main Video
- `object-fit: cover`
- Draggable Brand Name

### Floating Mentor Camera

- Bottom-right বা configurable position
- Draggable
- Label: **Shah Neil Khan**
- Custom background / blur support

### Side / Floating Teleprompter

- Mentor-only reading panel
- Voice-to-text content
- Scrollable text
- Recording-এর সময় visible
- Final recorded video-তে invisible

### Bottom Control Bar

Suggested controls:

- 🎙 Microphone
- 📹 Camera
- 🔴 Record
- 📝 Voice Text
- 🖼 Background
- 🌫 Blur
- 👥 Student View
- ⚙ Settings

## 15. Recording Architecture Requirement

Recording system এমনভাবে তৈরি করতে হবে যাতে:

### Visible UI

→ Main Video  
→ Mentor Camera  
→ Brand Label  
→ Teleprompter  
→ Controls  

কিন্তু

### Final Recorded Video

→ Main Video  
→ Mentor Camera  
→ Brand Label  

এবং:

### Teleprompter

→ Screen-এ থাকবে  
→ Final video-তে থাকবে না

এটি সম্ভব করার জন্য recording composition/canvas এবং UI layer আলাদা রাখা উচিত।

## 16. Overall Goal

একটি **Zoom-style premium video recording interface** তৈরি করা হবে যেখানে:

- Main video বড় ও full-stage হবে
- Mentor camera draggable হবে
- Mentor name visible থাকবে
- Brand label draggable হবে
- Voice থেকে automatic text তৈরি হবে
- Teleprompter Mentor-এর screen-এ দেখা যাবে
- Recording-এর সময় Teleprompter ব্যবহার করা যাবে
- Final video-তে Teleprompter থাকবে না
- Camera background custom image বা blur করা যাবে
- Student view optional এবং ছোট রাখা যাবে
- Green accent color থাকবে
- Glassmorphism UI থাকবে
- পুরো interface professional, modern এবং easy-to-use হবে
